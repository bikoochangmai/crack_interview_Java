## Run a useful mock

1. Pick questions before opening the answers. Set an appropriate timebox for your practice session.
2. Clarify inputs, scope and success/failure behavior aloud.
3. Produce a solution and explain why it is correct, then test boundaries.
4. Read the model answer and identify missing reasoning rather than memorize wording.
5. Answer the follow-ups; revisit any gap in the linked full tutorial.

## How to score yourself

Score each dimension 0 (missing), 1 (partial) or 2 (clear): contract, correctness/invariant, failure/boundary analysis, complexity/scale, and verification/communication. This is a self-review rubric, not a hiring prediction. For AI rounds also demonstrate independent ownership, data boundaries and evidence.
