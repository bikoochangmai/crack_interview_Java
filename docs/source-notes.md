- **Existing question bank:** 167 questions from the previously created GitHub Pages portal. Condensed model-answer cues are preserved in topic-wise Markdown files.
- **Kafka PDF:** 65 questions from *Kafka Interview Questions and Answers Senior/Staff* (10 pages). Answers were extracted and normalized into Markdown and the portal JSON. Review publishing rights before publishing this derived material to a public repository.
- **Java Senior Concurrency Interview Guide:** Topic-level synthesis into `java-concurrency-senior.md` with independent wording and additional version-sensitive caveats.
- **Java Senior/Lead Concurrency Interview Handbook:** Marked **Confidential & Proprietary**. Its text and code have **not** been reproduced in the public-ready files. Obtain explicit publication permission before adding any content from it.
- **Accuracy:** Uploaded PDFs contain specific timing/stack size and JVM implementation claims that are not portable guarantees. The concurrency summary avoids universal numerical claims and distinguishes Java 21 from later Java releases.
- **Privacy:** Never commit proprietary internal code, credentials, customer data or unpublished company materials to a public GitHub Pages repository.
